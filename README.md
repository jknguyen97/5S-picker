## Purpose


Team selector for weekly lab 5s (Sort, Set, Shine, Standardize, Sustain).



## Local Installation and Setup



Running the app:



### 1. Clone the Repository

```bash

git clone https://github.com

cd 5S-picker

```



### 2. Install Dependencies

Make sure you have Python installed, then install the required libraries (streamlit \& network):

```bash

pip install -r requirements.txt

```



### 3. Run the App

Launch local Streamlit server:

```bash

streamlit run 5s\_picker.py

```
